LEARNING ATLAS | INK & DISCIPLINE

A self-contained study-record web app for twelve selected Coursera specializations.

HOW TO OPEN
- Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
- No installation, internet connection, or server is needed for the app itself.
- The Coursera links open the official course catalogue in a separate tab.

PROGRESS
- All concept statuses begin as Not started.
- Click the symbol next to a concept: Not started -> Studying -> Mastered -> Not started.
- Course and module controls can bulk-mark or clear concepts.
- Search using Ctrl+K or the search icon.
- Star concepts for later review; use pencil icons to add concept notes.
- Keep standalone study reflections in Field journal.

DATA
- All data remains in this browser's local storage.
- Use Export record to download a JSON backup regularly.
- Restore a previous record from the Options menu > Restore study record.
- Clearing browser data may remove progress unless you have exported a backup.

CATALOGUE
- 12 specializations / 45 courses / 180 curated study modules / 720 key concepts.
- Course titles reflect Coursera's listed programs as checked November 3, 2026.
- Module headings and key concept outlines are editorially curated for tracking;
  they are not a verbatim reproduction of every Coursera weekly syllabus.
- The app contains no business, simulator-project or external-program trackers.
